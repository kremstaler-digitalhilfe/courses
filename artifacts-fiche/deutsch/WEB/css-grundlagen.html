1. CSS-Vokabular (Syntax)

Eine CSS-Regel folgt immer demselben festen Schema:

selektor {
  eigenschaft: wert;
}

1Selektor

Was soll gestaltet werden?

  • Sagt, welches HTML-Element gestaltet wird.
  • p = alle Absätze, h1 = Überschriften

2Eigenschaft

Property – Was soll sich ändern?

  • color = Textfarbe
  • font-size = Schriftgröße

3Wert

Value – Wie soll es sich ändern?

  • blue = Blau
  • 16px = Größe

Beispiel:

h1 {
  color: blue;
  font-size: 24px;
}

↑ Das macht alle Hauptüberschriften blau und 24 Pixel groß.

CSS einbinden

2. Wie kommt CSS in die Website?

Es gibt drei Wege, CSS einzubinden. Der beste und wichtigste Weg ist die externe Datei.

1Externe Datei

Der Standard ★

  • Eine separate .css-Datei, z. B. style.css
  • Wird im <head> der HTML-Datei verknüpft:
  • <link rel="stylesheet" href="style.css">
  • Hält den Code sauber und übersichtlich.

2Interner Bereich

Direkt in der HTML-Datei

  • Innerhalb eines <style>-Tags
  • Das Tag steht im <head>.

3Inline-CSS

Vermeiden! ✗

  • Direkt am jeweiligen HTML-Element:
  • <p style="color: red;">
  • Macht den Code unübersichtlich und schwer zu pflegen.
Goldene Regel: Externe Datei benutzen – Inline-CSS vermeiden!

Zum Vergleich

Extern

  • Sauber ✓
  • Übersichtlich ✓
  • Standard ✓

Intern

  • Im <style>-Tag
  • Im <head>

Inline

  • Am Element
  • Schwer zu pflegen

3. Die wichtigsten Eigenschaften

1Farben

color & background-color

  • color ändert die Textfarbe.
  • background-color ändert die Hintergrundfarbe.

padding · Innenabstand

  • Der Innenabstand – zwischen Text und Rahmen.

2margin

  • Der Außenabstand – Abstand zu anderen Elementen.

3border

  • Ein sichtbarer Rahmen um das Element.

Flexbox

Positionierung · 1-dimensional

1Was ist Flexbox?

Flexible Box Layout

  • Ein modernes Werkzeug, um Elemente flexibel anzuordnen und auszurichten.
  • Früher war es kompliziert, Boxen nebeneinander zu positionieren oder perfekt zu zentrieren.
  • Flexbox löst das: Ein Container bestimmt, wie sich seine Elemente automatisch an den verfügbaren Platz anpassen.

Die zwei Teile

1Flex-Container

  • Das äußere Eltern-Element, das Flexbox aktiviert.

2Flex-Items

  • Die inneren Elemente, die nun flexibel verschoben werden können.
So sieht es aus – eine Zeile
Item 1Item 2Item 3
↑ Flex-Container (gestrichelt) mit drei Flex-Items
Merke dir: Flexbox ist für entweder eine Zeile ODER eine Spalte gemacht.

Arbeitsweise

  • Elemente werden in eine Richtung angeordnet (z. B. nebeneinander) und passen sich flexibel an den Platz an.

Typische Anwendungen

  • Navigationsleisten (Links nebeneinander)
  • Kleine Gruppen von Buttons oder Icons
  • Elemente zentrieren

CSS Grid

Positionierung · 2-dimensional

2Was ist CSS Grid?

Wie ein Schachbrett oder ein kariertes Blatt Papier

  • Gemacht für Zeilen UND Spalten gleichzeitig.
  • ArbeitsweiseDu definierst ein festes Raster aus Spalten und Zeilen und platzierst die Inhalte genau dort, wo du sie haben willst.
So sieht es aus – ein Raster
HeaderSidebarHauptinhaltFooter

Typische Anwendungen

  • Das komplette Layout einer Website (Header, Sidebar, Hauptinhalt, Footer)
  • Bildergalerien mit vielen Kacheln
  • Komplexe Formulare oder Dashboards

Üben & Nachschlagen

  • cssgridgarden.com
  • CSS-Tricks: Complete Guide to Grid

4. Die Faustregel

Flexbox nutzen, wenn …

  • Elemente in eine Richtung fließen sollen (waagerecht oder senkrecht).

Grid nutzen, wenn …

  • du eine ganze Fläche in Zeilen und Spalten aufteilen musst.
Tipp: In der Praxis schließen sich die beiden nicht aus. Meistens nutzt man Grid für das große Layout der gesamten Website und Flexbox für die kleinen Details im Inneren (z. B. Logo und Menüpunkte nebeneinander in der Kopfzeile).

CSS & Barrierefreiheit

4. Barrieren abbauen statt schaffen

Auch mit CSS kannst du Barrieren für Nutzer schaffen oder abbauen:

1Fokus-Rahmen erhalten

Nie ohne Ersatz entfernen!

  • Nutze niemals outline: none; ohne einen eigenen, gut sichtbaren Fokus-Rahmen.
  • Tastaturnutzer müssen jederzeit sehen, auf welchem Element sie sich befinden.

2Gute Kontraste

Text und Hintergrund klar trennen

  • Text und Hintergrund müssen sich deutlich voneinander abheben.
  • So können auch Menschen mit Sehbehinderungen alles problemlos lesen.

3Schriftgröße skalierbar

rem statt px

  • Am besten relative Einheiten (wie rem) statt fester Pixel (px).
  • So können Nutzer die Schrift im Browser problemlos vergrößern.

Zusammenfassung

CSS = Design, keine Programmierung Selektor { Eigenschaft: Wert; } Externe Datei = Standard Flexbox 1D · Grid 2D
Merke dir: Gutes CSS …
  • liegt in einer externen Datei
  • nutzt Flexbox für eine Richtung und Grid für Flächen
  • erhält den Fokus-Rahmen und sorgt für gute Kontraste
  • nutzt rem statt px für Schriftgrößen
