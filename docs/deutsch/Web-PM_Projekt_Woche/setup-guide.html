Schritt 1 · Visual Studio Code installieren

1Visual Studio Code (VS Code)

Kostenloser Code-Editor

  1. Öffne die Download-Seite: code.visualstudio.com/download (öffnet in neuem Tab)
  2. Lade den passenden Installer für dein Betriebssystem (Windows oder macOS) herunter.
  3. Führe die Installation mit den Standardeinstellungen durch und öffne VS Code einmal zum Testen.
  4. Optional für den WEB-Bereich: Extension Live Server installieren.

Schritt 2 · Node.js installieren

2Node.js

Laufzeitumgebung für moderne Webprojekte

  1. Gehe zu w3schools.com/nodejs/… (öffnet in neuem Tab) und mache den Schritt „Verify Installation“.
  2. Wenn du noch kein Node.js hast: gehe zu nodejs.org/en/download (öffnet in neuem Tab) und scrolle bis „Or get a prebuilt Node.js® for“ – wähle dein Betriebssystem und deinen Prozessor aus und lade den Installer herunter.
  3. Installiere Node.js und prüfe danach im Terminal / in PowerShell mit node -v.
Verify Installation→ ggf. installieren→ Node.js bereit

Schritt 3 · Git installieren

Hier geht es nur um die Installation – die Einführung in Git folgt später.

3aWindows

Installer von der Website

  1. Öffne git-scm.com (öffnet in neuem Tab).
  2. Lade den Windows-Installer herunter.
  3. Klicke immer auf Next. Die Standardeinstellungen passen.
  4. Prüfen in PowerShell: git --version

3bmacOS

Zwei Wege

  1. Mit Homebrew: brew install git
  2. Ohne Extra-Software: git --version im Terminal eingeben.
  3. macOS fragt nach den Xcode Command Line Tools. Klicke auf Installieren.
  4. Prüfe danach noch einmal mit git --version.
Tipp: Steht eine Versionsnummer da, ist Git installiert.

Schritt 4 · GitHub-Account erstellen

4Kostenloses GitHub-Konto anlegen

Für dein Projekt-Repository & das Kanban-Board

  1. Öffne github.com (öffnet in neuem Tab) und klicke auf Sign up (Registrieren).
  2. Du kannst dich klassisch mit E-Mail-Adresse, Passwort und Benutzernamen anmelden – oder direkt per Social Sign-up (z. B. Continue with Google oder Apple).
  3. Wähle einen klaren, seriösen Benutzernamen (z. B. Vor- und Nachname) und bestätige falls gefragt deine E-Mail-Adresse / Sicherheitsprüfung.
  4. Wähle den kostenlosen Free-Plan (keine Zahlungsdaten nötig) und melde dich an.
Tipp: Merke dir deine GitHub-Anmeldedaten und deinen Benutzernamen – beides brauchen wir zu Beginn der Projektwoche.

Schritt 5 · Eigenes Repository aus Vorlage erstellen

Deine persönliche Kopie des Astro-CV-Templates auf GitHub

5Neues Repository über das Template anlegen

Öffentliche Vorlage: https://github.com/kremstaler-digitalhilfe/astro-beginner-cv.git

  1. Melde dich auf GitHub an und öffne das öffentliche Template-Repository: github.com/kremstaler-digitalhilfe/astro-beginner-cv (öffnet in neuem Tab)
  2. Klicke oben rechts auf Use this template → Create a new repository.
  3. Gib deinem eigenen Repository einen Namen (z. B. mein-cv-portfolio) und wähle als Sichtbarkeit Public.
  4. Klicke auf Create repository – schon liegt dein eigenes Projekt-Repository in deinem GitHub-Account!
Tipp: Mit Use this template bekommst du eine saubere eigene Kopie der Vorlage unter deinem eigenen Benutzernamen. Wähle Public, damit das Klonen im nächsten Schritt ohne Anmeldung klappt und spätere Website-Veröffentlichungen problemlos funktionieren.

Schritt 6 · Dein Repository klonen (git clone)

6Projekt auf deinen Computer herunterladen

Aus GitHub in einen lokalen Ordner

  1. Öffne dein neu erstelltes Repository auf GitHub (unter deinem Benutzernamen).
  2. Klicke auf den grünen Button Code und kopiere die HTTPS-URL (endet auf .git).
  3. Öffne in VS Code ein Terminal (Terminal → New Terminal) und wechsle in deinen gewünschten Ordner (z. B. cd Desktop oder cd Documents).
  4. Führe git clone mit deiner kopierten URL aus und wechsle in den von Git erstellten Ordner:
git clone https://github.com/<dein-benutzername>/mein-cv-portfolio.git
cd mein-cv-portfolio
Tipp: Öffne den heruntergeladenen Ordner anschließend in VS Code (File → Open Folder… oder code . im Terminal).

Schritt 7 · Projekt lokal starten

7Abhängigkeiten installieren & Dev-Server starten

Astro-Projekt im Browser ansehen

  1. Stelle im VS Code Terminal sicher, dass du im Projektordner bist. Der aktuelle Pfad wird im Terminal angezeigt.
  2. Installiere einmalig alle benötigten Pakete mit npm install.
  3. Starte danach den lokalen Entwicklungsserver mit npm run dev.
  4. Öffne die angezeigte Adresse im Browser (meist http://localhost:4321).
npm install
npm run dev

Schritt 8 · Erste Änderung machen & committen

8Kleine Test-Änderung speichern & git commit

Deinen ersten eigenen Speicherstand erstellen

  1. Öffne in VS Code eine Datei (z. B. src/data/cv.json oder src/pages/index.astro), ändere eine Kleinigkeit (z. B. deinen Namen) und speichere (Ctrl + S / Cmd + S – bei aktiviertem Auto Save nicht nötig).
  2. Prüfe im Browser auf localhost:4321, ob die Änderung sofort sichtbar ist.
  3. Öffne ein zweites Terminal in VS Code (oder stoppe den Server mit Ctrl + C), prüfe den Status, merke die Änderung vor und committe sie:
git status
git add .
git commit -m "Erste Änderung: Name angepasst"
Tipp: Falls Git beim ersten Commit nach Name und E-Mail fragt, führe einmalig git config --global user.name "Dein Name" und git config --global user.email "deine@email.at" aus und wiederhole danach git commit.

Schritt 9 · Änderungen auf GitHub hochladen (git push)

9Aus VS Code pushen & einmalig im Browser anmelden

Kein extra Passwort-Token oder SSH-Schlüssel nötig

  1. Führe im VS Code Terminal git push aus (oder klicke in VS Code links bei Source Control auf Sync Changes / Push).
  2. Beim allerersten push fragt VS Code nach der GitHub-Anmeldung: Klicke auf Allow / Sign in with your browser.
  3. Melde dich im geöffneten Browser-Fenster bei GitHub an und bestätige mit Authorize Visual-Studio-Code.
  4. Lade dein GitHub-Repository im Browser neu – dein erster Commit ist jetzt auf GitHub sichtbar!
git push
Tipp: VS Code merkt sich deine Anmeldung – bei den nächsten git push-Befehlen musst du dich nicht erneut im Browser einloggen.
Checkliste vor dem Start:
  • VS Code, Node.js (node -v) und Git (git --version) funktionieren
  • GitHub-Account erstellt & eigenes Repository aus astro-beginner-cv angelegt
  • Repository lokal geklont (git clone) und auf localhost:4321 gestartet
  • Erste kleine Änderung gemacht, mit git commit gespeichert und per git push hochgeladen
