Clean Code Prinzipien

Programmieren · Die wichtigsten Prinzipien

1DRY

Don't Repeat Yourself

  • IdeeVermeide doppelten Code.
  • Gleiche Logik an mehreren Stellen? → in eine gemeinsame Funktion auslagern.
  • VorteilÄnderung nur an einer Stelle statt in dutzenden Dateien.

2KISS

Keep It Simple, Stupid

  • IdeeCode so einfach wie möglich halten.
  • Immer den unkompliziertesten Weg wählen, nicht den „cleveren“.
  • VorteilLeichter zu lesen, debuggen und erweitern.

3YAGNI

You Aren't Gonna Need It

  • IdeeKeine Features auf Vorrat programmieren.
  • „Vielleicht brauchen wir das irgendwann“ reicht nicht.
  • VorteilKeine verschwendete Zeit, keine aufgeblähte Codebasis.

4Namen & kleine Funktionen

Code, der sich wie ein Buch liest

  • IdeeSprechende Namen: isUserLoggedIn statt flag
  • Sehr kleine Funktionen mit einer klaren Aufgabe.
  • VorteilSelbsterklärend → weniger Kommentare nötig.

Eselsbrücke

DRY → nicht wiederholen KISS → einfach halten YAGNI → nichts auf Vorrat
Merke dir: Guter Code …
  • enthält keine Wiederholungen (DRY)
  • ist einfach gehalten (KISS)
  • enthält nur, was wirklich gebraucht wird (YAGNI)
  • erklärt sich durch gute Namen und kleine Funktionen selbst
