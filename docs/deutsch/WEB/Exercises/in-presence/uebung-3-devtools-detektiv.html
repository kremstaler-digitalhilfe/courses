Übung 3: DevTools Detektiv

WEB · Präsenz · ca. 15 Min.

Ziel

Der Browser ist dein Live-Testlabor

  • Den Browser als Werkzeug zum Untersuchen nutzen
  • Verstehen: der Client zeigt den Code nur an – Änderungen sind temporär
Tipp: Öffne eine beliebige Website (z. B. Wikipedia). Dann F12 – oder Rechtsklick → Untersuchen.

Drei Missionen

1Elements · Text ändern

Maus-Auswahl-Tool (Pfeil oben links)

  • Eine große Überschrift auf der Seite auswählen
  • Im HTML-Code den Text Doppelklick → ändern
  • FrageWas passiert auf der Seite?

2Elements · CSS Pink

Styles-Ansicht in den DevTools

  • Die Hintergrundfarbe der Seite finden
  • Auf ein grelles Pink ändern (z. B. hotpink)
  • Sofort sichtbar – nur bei dir!

3Console · alert

JavaScript direkt im Browser tippen

  • Zum Tab Console wechseln
  • Eingeben: alert("Hallo Welt!");
  • Enter drücken – was siehst du?

Was bedeuten die Missionen?

Übung 3 · Client vs. Server

Goldene Regel: Änderungen in den DevTools sind nur bei dir und nur bis zum Neuladen. Die echte Website bleibt gleich – der Client stellt dar, er speichert nicht.

Fertig-Check

Kannst du …

  • die DevTools mit F12 oder Rechtsklick öffnen?
  • im Tab Elements Text und Farbe ändern?
  • in der Console einen alert ausführen?
  • erklären, warum nach Neuladen alles wieder normal ist?

Zusammenfassung

Merke dir:
  • DevTools = Detektiv-Werkzeug im Browser
  • Elements = HTML & CSS ansehen und testen
  • Console = JavaScript live ausprobieren
  • Alles nur temporär – der Server bleibt unberührt

Glossar

DevTools: Entwicklerwerkzeuge im Browser (untersuchen, testen, debuggen).
Elements: Tab, der den HTML-Baum und die CSS-Regeln zeigt.
Console: Tab zum Tippen und Ausführen von JavaScript.
Client: Dein Browser – empfängt und stellt die Seite dar.
Server: Computer, der die Original-Datei der Website speichert.
alert(): Zeigt ein kleines Pop-up mit einer Nachricht.
