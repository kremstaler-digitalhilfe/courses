Übung 2: Begrüßungs-Generator

WEB · Präsenz · ca. 20 Min.

Ziel

JavaScript macht die Seite lebendig

  • Verstehen, wie eine eigene Funktion auf Nutzereingaben reagiert
  • Inhalte dynamisch auf der Website verändern
  • In CodePen.io einen interaktiven Namens-Generator bauen
Tipp: Öffne CodePen.io/pen (öffnet in neuem Tab) → „Start Coding“. Nutze diesmal HTML, CSS und JS.

Die Aufgabe – 3 Fenster

1HTML-Fenster

Grundgerüst

  • Überschrift <h2> für den Titel
  • Eingabefeld <input type="text">
  • Button <button> zum Auslösen
  • Absatz <p> für die Ausgabe

2CSS-Fenster

Schönes Design

  • Alles zentrieren, Hintergrundfarbe setzen
  • Eingabe, Button und Schrift stylen
  • Farben, Abstände, abgerundete Ecken

3JS-Fenster

Logik mit einer eigenen function

  • Wert aus dem Eingabefeld auslesen
  • Prüfung: ist das Feld leer? → Warnung
  • Personalisierte Willkommensnachricht im Ausgabefeld zeigen
Name tippen→ Button klicken→ Funktion läuft→ Text ändert sich

Übung 2 · Ideen für den Code

Beispiel – HTML + JS

<h2>Begrüßungs-Generator</h2>
<input type="text" id="name">
<button onclick="begruessen()">Los</button>
<p id="ausgabe"></p>
function begruessen() {
  const name = document.getElementById("name").value;
  if (name === "") {
    alert("Bitte einen Namen eingeben!");
    return;
  }
  document.getElementById("ausgabe").textContent =
    "Willkommen, " + name + "!";
}
Goldene Regel: Die Funktion liest den Input, prüft ihn, und schreibt danach in das Ausgabefeld – so wird die Seite dynamisch.

Zusammenfassung

Merke dir:
  • HTML = Gerüst · CSS = Design · JS = Reaktion
  • Eine function bündelt die Logik (lesen → prüfen → ausgeben)
  • Leere Eingaben immer prüfen – sonst falsche Begrüßung

Glossar

function: Eigenes Stück Code mit einem Namen – wird bei Bedarf aufgerufen.
input: Eingabefeld, in das Nutzer Tippen können.
value: Der aktuelle Text im Eingabefeld.
getElementById: Findet ein HTML-Element über seine id.
textContent: Setzt oder liest den Text eines Elements.
dynamisch: Die Seite ändert sich, während man sie benutzt.
