Übung 1: Digitale Visitenkarte

WEB · Präsenz · ca. 20 Min.

Ziel

Ohne Installation – direkt im Browser

  • Verstehen, wie HTML (Struktur) und CSS (Design) zusammenarbeiten
  • Eine Mini-Visitenkarte in CodePen.io bauen
Tipp: Öffne CodePen.io/pen → „Start Coding“. Du brauchst nur die Fenster HTML und CSS.

Die Aufgabe

Erstellt eine Mini-Visitenkarte im Browser.

1HTML-Fenster

Struktur = Inhalt

  • Überschrift <h1> für den Namen
  • Absatz <p> für Beruf / Bio
  • Button <button>Kontakt</button>

2CSS-Fenster

Design = Aussehen

  • Hintergrundfarbe der Seite (background-color)
  • Schriftfarbe und Schriftgröße ändern
  • Alles zentrieren

Beispiel – Starthilfe

<h1>Alex Müller</h1>
<p>Web-Designerin · Hamburg</p>
<button>Kontakt</button>

body {
  background-color: #fbd3e4;
  color: #2b2b3a;
  font-size: 20px;
  text-align: center;
}
HTML = Was steht da? + CSS = Wie sieht es aus? → Visitenkarte ♥
Goldene Regel: HTML baut die Bausteine. CSS malt sie an – ohne HTML gibt CSS nichts zu stylen.

Zusammenfassung

Merke dir:
  • HTML = Bausteine (h1, p, button)
  • CSS = Design (Farbe, Schrift, Zentrierung)
  • Beide zusammen → eine sichtbare Visitenkarte
  • Beispiellösung: codepen.io/kremstaler-digitalhilfe/pen/vExVqez

Glossar

HTML: Auszeichnungssprache für die Struktur einer Webseite.
CSS: Stylesheet-Sprache für das Aussehen (Farben, Layout).
<h1>: Wichtigste Überschrift – hier der Name.
<p>: Absatz für Fließtext (Beruf, Bio).
<button>: Klickbares Element auf der Seite.
background-color: CSS-Eigenschaft für die Hintergrundfarbe.
