Übung 5: Ordner & Live Server

WEB · SOL · VS Code · ca. 25 Min.

Ziel

So arbeiten Profis auf dem eigenen Rechner

  • Einen lokalen Projektordner anlegen
  • Drei Dateien nebeneinander: index.html, style.css, script.js
  • Die Seite mit Live Server im Browser öffnen
Ordner→ 3 Dateien→ Speichern→ Go Live

Die 5 Schritte

1VS Code

  • Visual Studio Code herunterladen und starten.

2Ordner anlegen

  • Auf dem Desktop: meine-erste-website.

3In VS Code öffnen

  • Ordner per Drag & Drop ins Fenster ziehen.

4Drei Dateien

  • Oben links: Neue Datei
  • Exakt so nennen: index.html, style.css, script.js

5Einfügen & speichern

  • Code von den nächsten Seiten kopieren
  • Cmd + S (Mac) oder Strg + S (Windows)

Go Live

  • index.html öffnen
  • Unten rechts: Go Live — oder Rechtsklick → Open with Live Server
Tipp: Die Erweiterung Live Server muss in VS Code installiert sein. Danach öffnet sich der Browser von selbst.

Ordner-Struktur

Alle drei Dateien nebeneinander

Im Projektordner liegen die Dateien direkt nebeneinander – keine Extra-Unterordner.

HTML = Gerüst + CSS = Haut + JS = Muskeln
Goldene Regel: CSS kommt im <head> (link rel="stylesheet"). JavaScript kommt ganz unten im body (<script src="script.js">).

index.html – kopieren

<!DOCTYPE html>
<html lang="de">
<head>
    <meta charset="UTF-8">
    <title>Meine erste Website</title>
    <!-- Die Haut -->
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="card">
        <h1>Hallo Welt! 🚀</h1>
        <p>Mein erstes Web-Projekt.</p>
        <button id="actionBtn">Klick mich!</button>
    </div>
    <!-- Die Muskeln – ganz unten -->
    <script src="script.js"></script>
</body>
</html>

/* Alles zentrieren */
body {

    justify-content: center;
    align-items: center;

    border: none;

script.js – kopieren

// 1. Button holen
const button = document.getElementById("actionBtn");

// 2. Auf Klick warten
button.addEventListener("click", function() {
    alert("Super gemacht! Dein JavaScript funktioniert!");
    // 3. Bonus: Button ändern
    button.textContent = "Geklickt! ✅";
    button.style.backgroundColor = "#2ecc71";
});

Live Server & Check

Übung 5 · Fertig?

So startest du

1index.html öffnen

  • Die Datei in VS Code anklicken.

2Go Live

  • Unten in der blauen Leiste Go Live – oder Rechtsklick → Open with Live Server.

Der Browser öffnet sich. Du siehst die Karte. Ein Klick auf den Button startet JavaScript (Alert + grüner Button).

index.html→ Go Live→ Browser zeigt die Karte

Fertig-Check

Kannst du …

  • den Ordner meine-erste-website in VS Code öffnen?
  • die drei Dateien nebeneinander anlegen und speichern?
  • CSS im head und JS unten im body verknüpfen?
  • mit Go Live die Karte im Browser sehen und klicken?

Zusammenfassung

Merke dir:
  • Ein Projekt = ein Ordner mit html, css und js nebeneinander
  • Immer speichern, bevor du im Browser prüfst
  • Live Server zeigt die echte lokale Website – wie Profis arbeiten

Glossar

VS Code: Editor, in dem du Dateien schreibst und speicherst.
Live Server: Erweiterung, die die Seite im Browser live zeigt.
index.html: Startseite eines Projekts – der Browser öffnet sie zuerst.
href / src: Pfad zur CSS-Datei (link) bzw. zur JS-Datei (script).
getElementById: Findet ein HTML-Element über seine id.
addEventListener: Wartet auf ein Ereignis, z. B. einen Klick.
