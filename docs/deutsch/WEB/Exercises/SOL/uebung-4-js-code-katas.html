3 · Gerade oder ungerade?

3Even or Odd

  • Prüfe, ob eine Zahl gerade oder ungerade ist
  • Gib den Text "Gerade" oder "Ungerade" zurück
Tipp: zahl % 2 === 0 → kein Rest → die Zahl ist gerade.

4 · Preisrechner mit Rabatt

4Aufgabe

  • Parameter: Preis und Rabatt in %
  • Berechne den reduzierten Preis
  • Gib einen Text zurück, z. B. "New price: 80 €"
100 € · 20 %→New price: 80 €

Zusammenfassung

Merke dir:
  • Funktion = Input → Rechnung → return
  • % = Rest der Division (gerade / ungerade)
  • Rabatt: neuer Preis = Preis − (Preis × Prozent / 100)
  • Beispiellösungen:
    1: codepen.io/…/OPpBeZe (öffnet in neuem Tab)
    2: codepen.io/…/vExVqrQ (öffnet in neuem Tab)
    3: codepen.io/…/rayqEZw (öffnet in neuem Tab)
    4: codepen.io/…/ogZarVa (öffnet in neuem Tab)

Glossar

function: Benanntes Stück Code mit Parametern und Rückgabewert.
return: Schickt das Ergebnis aus der Funktion zurück.
Modulo %: Rest einer Division (z. B. 5 % 2 = 1).
Parameter: Wert, den du der Funktion übergibst.
Kata: Kleine Übungsaufgabe zum Trainieren.
Rabatt %: Anteil vom Preis, der abgezogen wird.
