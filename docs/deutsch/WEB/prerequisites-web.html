Kompakte Übersicht: Was du vor dem Kurs brauchst.

Kurs-Checkliste (notwendig)

1Computer / Laptop

  • Internetverbindung
  • Moderner Browser: Chrome oder Firefox

2CodePen.io

Gratis-Account

  • Für Browser-Übungen (Präsenz)
  • Tipp: /pen ans Ende der URL → vereinfachte Ansicht

CodePen.io/pen (öffnet in neuem Tab)

3Visual Studio Code

Kostenloser Editor

  • Extension: Live Server
  • Für das lokale Projekt im Selbststudium (SOL)

code.visualstudio.com/download (öffnet in neuem Tab)

4Vorkenntnisse

  • Keine – der Kurs startet bei Null
Laptop + Browser→ CodePen→ VS Code + Live Server

Node.js Installation

So gehst du vor

  • Gehe zu w3schools.com/nodejs/… (öffnet in neuem Tab) und mache den Schritt „Verify Installation“
  • Wenn du kein Node.js hast: gehe zu nodejs.org/en/download (öffnet in neuem Tab) und scrolle bis „Or get a prebuilt Node.js® for“ – wähle dein Betriebssystem und Prozessor aus und downloade dein Installer
Verify Installation→ ggf. installieren→ Node.js bereit
Tipp: CodePen reicht für die ersten Übungen. VS Code + Live Server brauchst du später für den lokalen Ordner.
Merke dir:
  • Browser + Internet = Basis
  • CodePen = schnell im Browser üben
  • VS Code + Live Server = echtes lokales Projekt
  • Keine Vorkenntnisse nötig

Glossar

Browser: Programm zum Anzeigen von Webseiten (Chrome, Firefox).
CodePen: Online-Editor für HTML, CSS und JavaScript.
VS Code: Kostenloser Code-Editor auf dem eigenen Rechner.
Live Server: VS-Code-Extension, die die Seite lokal im Browser zeigt.
Node.js: Laufzeitumgebung für JavaScript außerhalb des Browsers.
/pen: URL-Ende bei CodePen für die einfache Editor-Ansicht.
