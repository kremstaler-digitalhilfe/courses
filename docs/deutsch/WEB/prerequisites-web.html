Node.js prüfen

Terminal · Version checken

Zuerst das Terminal öffnen – dann eine kurze Prüfung.

1. Terminal öffnen

WinWindows

  • Taste Windows drücken
  • cmd oder Terminal tippen
  • Eingabeaufforderung / Terminal öffnen

Schnell: Win + R → cmd → Enter

MacmacOS

  • Cmd + Leertaste (Spotlight)
  • Terminal tippen
  • Enter – das Fenster öffnet sich

Oder: Programme → Dienstprogramme → Terminal

2. Befehl ausführen

Kopieren → ins Terminal einfügen → Enter.

node -v

Ergebnis OK

  • Du siehst eine Version, z. B. v22.11.0
  • Node.js ist installiert – fertig

Noch nicht da?

  • Meldung wie command not found / nicht erkannt
  • Dann unten installieren und danach node -v nochmal

3. Falls nötig: installieren

Download

  • Gehe zu nodejs.org/en/download (öffnet in neuem Tab)
  • Scrolle bis „Or get a prebuilt Node.js® for“
  • Wähle Betriebssystem + Prozessor → Installer laden → durchklicken
  • Terminal neu öffnen, dann wieder node -v
Terminal öffnen→ node -v→ ggf. installieren→ Node.js bereit
Merke dir:
  • Browser + Internet = Basis
  • CodePen = schnell im Browser üben
  • VS Code + Live Server = echtes lokales Projekt
  • node -v im Terminal = Node.js prüfen

Glossar

Browser: Programm zum Anzeigen von Webseiten (Chrome, Firefox).
CodePen: Online-Editor für HTML, CSS und JavaScript.
VS Code: Kostenloser Code-Editor auf dem eigenen Rechner.
Terminal: Textfenster, in dem du Befehle tippst (Windows / Mac).
Node.js: Laufzeitumgebung für JavaScript außerhalb des Browsers.
node -v: Befehl, der die installierte Node.js-Version zeigt.
