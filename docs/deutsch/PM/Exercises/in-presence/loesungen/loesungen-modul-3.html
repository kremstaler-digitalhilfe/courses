Lösungen Modul 3

PM · Präsenz · Tools · Lösungen

Richtige Antworten mit kurzer Erklärung.

1 · E-Mails & Zettel im Büro

1 Richtige Antwort: B

E-Mails verbleiben oft in persönlichen Postfächern und Informationen gehen für das Gesamtteam schnell verloren oder sind unauffindbar.

2 · Einführung von agilen Tools

2 Richtige Antwort: B

Software macht Arbeitsabläufe lediglich transparent. Ohne ein funktionierendes agiles Mindset, klare Rollen und Methodik löst ein Tool allein keine Organisationsprobleme.

3 · Tool-Paare für Aufgaben & Wissen

3 Richtige Antwort: B

Jira ist standardmäßig für die Vorgangs- und Aufgabenverwaltung (1) zuständig, während Confluence als zentrales Wiki für Wissensmanagement und Dokumentation (2) dient.

4 · Ticket-Typen in Jira

4 Richtige Antwort: C

Ein Task (oder Technical Task) beschreibt eine konkrete technische Arbeit (z. B. Server aufsetzen, Refactoring), die notwendig ist, aber für den Endnutzer keinen direkten funktionellen Mehrwert darstellt.

Lösungen 5–8

Modul 3 · Doku · Spike · Tools

5 · Single Source of Truth

5 Richtige Antwort: B

Informationen sollen zentral an einer Stelle gepflegt werden, damit alle Teammitglieder immer den aktuellsten Stand sehen und widersprüchliche Versionen oder veraltete Kopien vermieden werden.

6 · Agiler Spike

6 Richtige Antwort: B

Ein Spike ist eine zeitlich fest begrenzte Aufgabe (Timebox), in der das Team recherchiert oder Prototypen baut, um technische Unsicherheiten vor einer tatsächlichen Umsetzungs-Story zu klären.

7 · Vertikaler Schnitt von User Stories

7 Richtige Antwort: A

Ein vertikaler Schnitt durchdringt alle Schichten einer Anwendung (Datenbank, Logik, UI), sodass am Ende einer Story ein echtes, lauffähiges und testbares Inkrement für den Nutzer entsteht.

8 · Auswahl neuer Tools

8 Richtige Antwort: C

Neue Tools sollten schlank und einfach gehalten werden, um die Einstiegshürde niedrig zu halten und sicherzustellen, dass das gesamte Team das Board aktiv pflegt.

Zusammenfassung

Merke dir:
  • Tools machen sichtbar – ersetzen keine Methode
  • Jira = Aufgaben · Confluence = Wissen
  • Eine Info = ein Ort · Spike = kurze Recherche
  • Vertikal schneiden · lieber einfach starten

Glossar

Jira: Tool für Tickets, Backlog und Boards.
Confluence: Wiki für gemeinsames Wissen und Doku.
Task: Technische Aufgabe ohne direkten Kundennutzen.
Single Source of Truth: Eine Information an genau einem Ort.
Spike: Zeitlich begrenzte Recherche zu einer offenen Frage.
Vertikal schneiden: Stories liefern nutzbaren Nutzen über alle Schichten.
